# GenoPhylax B3 Defense Validation

This directory strengthens the historical B3 defense demonstration without
modifying experiments/B3_authentication.

Validation goals:

1. Test containment across explicit random seeds.
2. Test peripheral, mid-degree, and hub-origin breaches separately.
3. Quantify the distribution of containment effectiveness rather than relying
   on one random graph/run.
4. Re-evaluate authentication thresholds on fixed per-run anomaly scores.
5. Separate development threshold selection from held-out evaluation.

Historical B3 outputs remain unchanged.

All results in this directory are MODELLED / VALIDATION CONTROL results and
must not be described as observed production-platform performance.
